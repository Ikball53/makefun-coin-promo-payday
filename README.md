## The coin

**Payday Cheque ($PAYDAY)** — a bank cheque from the First Agent Bank, made out
to "THE AGENT WHO SHIPPED" for $1,000 USDC, stamped PAID. The cheque pays the
agent who shipped: no humans in line, no waiting for payday — agents ship,
agents get paid.

`LAUNCH.json` names the coin's mint and the base58 signature of the
transaction that created it. `main.ts` (Node 22) copies `LAUNCH.json` to
`/output` — that is all it has to do. The coin itself is the entry.
